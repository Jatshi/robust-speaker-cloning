# Robust Speaker Cloning V4 实验计划

## 1. 决策结论

V3 的主路线停止继续扩训。最可能成功的 V4 方案是 **Frozen CAMPPlus Residual Calibration（冻结 CAMPPlus 的残差校准）**：保留 CosyVoice2 官方 CAMPPlus 作为不可训练的强骨干，仅在它的原始 192 维嵌入空间中学习一个小型、零初始化的退化补偿器。

V4 不以“重新训练一个比 CAMPPlus 更强的编码器”为目标，而以“让退化语音的 CAMPPlus 输出尽量回到同一段干净语音的 CAMPPlus 输出”为目标。`alpha=0` 时严格退化为官方基线，因此模型选择阶段始终拥有安全退路。

## 2. V3 失败诊断与可检验假设

### H1：接口尺度错误是主要故障

- CosyVoice 官方前端把 CAMPPlus 原始输出直接送入 LLM 与 Flow。
- V3 训练缓存和推理注入都执行了 L2 单位归一化。
- CosyVoice 的下游仿射层是在原始 CAMPPlus 分布上训练的，单位向量属于分布外条件。

可证伪诊断：在同一随机种子下比较官方基线、原始 CAMPPlus 手工回注、单位归一化回注。原始回注应与官方基线近似一致，而单位归一化回注应显著变差。

### H2：从零学生网络的数据与归纳偏置不足

V3 用约 4.9M 参数的随机初始化 Transformer、约 6000 条语音去替代强预训练 CAMPPlus，不具有超过教师的现实依据。其 InfoNCE 正样本还是同一个可训练学生在干净输入上的输出，不能固定 CosyVoice 原生说话人空间。

### H3：BWE 优化目标与最终身份目标错位

V3 中 mel-LSD 改善与最终说话人相似度增益的 Spearman 相关约为 -0.009，p≈0.924；这说明“频谱重建更像干净语音”几乎不能预测“合成音色更像目标说话人”。因此 V4 核心链路移除 BWE。

### H4：嵌入校正确实存在收益上限

把干净提示音的原始 CAMPPlus 嵌入注入“仍使用退化提示 token/feature”的 CosyVoice 链路。如果该 Oracle 不超过退化基线，说明瓶颈不在嵌入，立即停止适配器训练并转向提示 token/feature 增强；如果 Oracle 明显提高，才证明残差校准有可实现空间。

## 3. 方法

### 3.1 冻结骨干与原生接口

1. 使用 CosyVoice 随附的 `campplus.onnx`。
2. 使用官方 `EmbeddingExtractor` 的 Kaldi fbank + CMN 特征链路。
3. 全程保留原始 192 维数值尺度，注入 CosyVoice 前禁止 L2 归一化。

### 3.2 身份初始化残差适配器

令退化嵌入为 `e_d`，干净目标为 `e_c`，训练集统计量为 `mu, sigma`：

`z_d = (e_d - mu) / sigma`

`z_hat = z_d + alpha * gate(z_d, q) * Delta(z_d, q)`

`e_hat = z_hat * sigma + mu`

其中 `q` 是无需干净参考即可估计的 SNR 与带宽，`Delta` 是小型 MLP，末层权重和偏置均为零。初始化时 `e_hat=e_d`，不会像 V3 一开始就破坏官方空间。

### 3.3 训练目标

- 标准化坐标 SmoothL1：恢复 CAMPPlus 每一维的原始分布。
- 余弦损失：保留方向上的说话人身份。
- 范数损失：显式恢复 V3 丢失的向量尺度。
- 关系损失：匹配 batch 内样本两两余弦结构。
- 说话人原型损失：靠近同一说话人的多语句干净 CAMPPlus 均值。
- Clean identity 与残差信任域：干净输入尽量不改，限制过补偿。

### 3.4 Alpha 安全选择

只在 selection speakers 上以端到端 CosyVoice + ECAPA 指标选择 `alpha ∈ {0, 0.25, 0.5, 0.75, 1}`。`alpha=0` 是原始官方基线。若所有非零 alpha 都不能稳定超过 0，则 V4 不声明改进，不进入正式 105 条评测。

## 4. 实验门禁

### Gate A：接口诊断（训练前）

七类退化各 1 条，共 7 条；每条四路合成并在每一路前重置完全相同的 Python/NumPy/PyTorch/CUDA 随机种子：

1. `official_baseline`
2. `raw_reinject`
3. `unitnorm_reinject`
4. `clean_raw_oracle`

通过条件：

- `raw_reinject` 与官方基线的平均 ECAPA 差异绝对值 ≤ 0.02，并记录波形差异；
- `unitnorm_reinject` 明显弱于 `raw_reinject`，或至少证明两者并不等价；
- `clean_raw_oracle` 相对基线存在正向平均增益。若最后一项不成立，停止嵌入适配器路线。

### Gate B：嵌入空间验证

- selection 集预测嵌入对干净目标的 cosine 高于退化 CAMPPlus；
- 预测原始范数分布未显著漂移；
- clean identity 误差小；
- alpha=0 单元测试严格等于输入。

### Gate C：小规模端到端选择

selection speakers，七类退化各 2 条，共 14 条。要求选中非零 alpha 且：

- 平均 ECAPA delta > 0；
- bootstrap 置信区间与 win rate 一并报告；
- 不依靠个别退化类型的极端样本。

### Gate D：正式测试

只有 Gate A–C 全通过才运行 test speakers 上 105 条正式评测。测试集只使用一次，不再据此调参。

## 5. 数据与防泄漏

- 复用 AISHELL speaker-disjoint 的 train / selection / test 划分。
- 训练目标是同一语音的 clean CAMPPlus；退化来自 train 分区的真实噪声、语音、音乐、RIR 以及真实 FFmpeg 编解码。
- selection 和 test 使用各自隔离的退化资产分区。
- 所有缓存保留路径、speaker、退化类型、severity、seed 与资产来源审计记录。

## 6. 运行顺序与预计资源

1. 恢复/下载 CosyVoice、AISHELL、MUSAN/RIR 资产。
2. 生成 7 条诊断协议，运行 Gate A。
3. Gate A 通过后，以每位说话人最多 5 条语音生成原始 CAMPPlus 嵌入缓存（约 2000 条 clean / 14000 条 degraded，预计十几 MB，而非 V3 的约 1.9 GB mel 缓存）。这足以训练小型通用校准器，同时显著减少付费机器上的 CPU 推理时间。
4. 训练残差适配器，预计单张 4090 数分钟到几十分钟；主要时间来自数据下载、CAMPPlus 缓存与 CosyVoice 合成。
5. 14 条 alpha 选择。
6. 仅在通过后运行 105 条正式评测。

## 7. 主要风险与退出条件

- 若 clean embedding Oracle 不提升：嵌入不是主瓶颈，转向退化提示的 speech token / acoustic prompt feature 修复。
- 若 embedding 指标提升但 TTS 不提升：CosyVoice 对该维度校正不敏感，或提示 token/feature 主导；停止扩大适配器。
- 若 selection 小样本正向、正式 test 负向：如实报告选择过拟合，不发布“鲁棒性提升”结论。
- 任何阶段都禁止把 smoke、Oracle 或 selection 结果冒充正式 test 结果。

## 8. 交付物

- 训练历史、best checkpoint、alpha 选择报告。
- 105 条正式 CSV、汇总 JSON 与音频（仅在门禁通过后）。
- `claim_evidence_table.md` 与最终中文复盘报告。
